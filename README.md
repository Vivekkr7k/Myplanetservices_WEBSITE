# Myplanetservices_WEBSITE

Official website and digital presence for My Planet Services — Premium Web Engineering, AI Automation, E-Commerce, Custom CRM/ERP, and Growth Architecture.

## Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + Vanilla CSS design tokens
- **Routing:** React Router
- **Icons:** Lucide React
- **Notifications:** Sonner
- **Scroll Smoothing:** Lenis Scroll

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
